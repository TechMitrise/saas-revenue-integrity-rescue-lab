# Rescue Lab Agent Guide

## Scope

This repository is the SaaS Revenue Integrity Rescue Lab. Its approved public journey is a synthetic paid-but-locked incident, duplicate webhook delivery, bounded entitlement-job failure, SLA breach, evidence-backed reconciliation, repeat no-op, and fragile-versus-stabilised proof.

Do not restore the former six generic billing anomalies as the primary demo. Do not add unrelated AI, codebase assessment, CRM, or marketing-site features.

## Safety

- Use only synthetic data and explicitly synthetic credentials.
- Never claim real customer outcomes or distributed exactly-once delivery.
- Keep workspace isolation and database constraints intact.
- Do not push, deploy, configure remotes, or use external credentials without explicit approval.
- Preserve immutable webhook and reconciliation evidence.

## Quality gate

Run `make test`, Composer/npm audits, scenario simulation, reconciliation/no-op verification, and the release audit before calling the project complete.
