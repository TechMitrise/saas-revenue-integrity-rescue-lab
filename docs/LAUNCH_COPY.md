## Short launch post

Payment succeeded. Access failed.

This Laravel rescue lab reproduces a revenue-critical SaaS failure end to end: ten webhook deliveries, one provider event, three failed entitlement attempts, a paid-but-locked incident, one safe repair and a verified repeat no-op.

It is deliberately synthetic, but the evidence is real application state: MySQL records, queue attempts, correlation IDs, before/after snapshots, PHPUnit assertions and desktop/mobile browser journeys.

Run the eight-action incident, inspect the code and challenge the recovery guarantee.
